# Install ST Novel Translator

## Direct SillyTavern Install

Use this URL in SillyTavern's extension installer:

```text
https://github.com/Zhuhui-02/st-novel-translator
```

The repository must be public or accessible to the SillyTavern runtime.

## Manual Install

Copy the full folder to:

```text
SillyTavern/public/scripts/extensions/third-party/st-novel-translator
```

Reload SillyTavern, open Extensions, and enable `Novel Translator`.

## First Test

1. Open the `Novel Translator` panel.
2. Paste a few chapters of plain text into `Import text`.
3. Click `Import`.
4. Select a segment.
5. Add glossary or name-table rows if needed.
6. Click `Build prompt`.
7. Click `Send to chat`.
8. Paste the model output into `Translation`.
9. Click `Save segment`.
10. Click `Run QA`.
